# Shipwreck and West Sea Object Reference Images

This directory contains visual references for 3D modeling and synthetic sonar-scene design. The files are divided into shipwreck references and priority-1 non-shipwreck objects relevant to a muddy or sandy coastal environment such as Korea's West Sea.

All image files were renamed in English, converted to `.jpg`, resized when necessary, and compressed for repository use. These are general modeling references, not field-survey records from Korea's West Sea.

## Suggested modeling use

- Use the shipwreck images for hull shape, structural breakage, exposed frames, burial, and debris distribution.
- Use the non-shipwreck images as negative or confusing objects in sonar scenes.
- Thin objects such as nets, ropes, and chains should be modeled as bundled, tangled, or attached to larger objects so that they produce detectable sonar returns and shadows.
- Vary object burial depth, orientation, sediment cover, scale, and acoustic material properties when generating synthetic data.
